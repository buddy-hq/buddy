Run one read-only SQLite query against the local standards knowledge graph database. Use this only when typed standards tools cannot answer the request. Prefer search_standards for candidates, get_standard for exact codes, and get_learning_components/get_prerequisites/get_next_standards/get_crosswalk for structured graph queries. Supports a single SELECT, WITH, PRAGMA, or EXPLAIN statement; results are capped by rowLimit and the connection is read-only.
