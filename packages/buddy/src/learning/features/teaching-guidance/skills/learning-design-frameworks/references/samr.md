# SAMR

SAMR is a technology integration model associated with Ruben Puentedura. The acronym stands for Substitution, Augmentation, Modification, and Redefinition. It is used to think about how technology changes a learning task: from direct replacement, to improved replacement, to significant redesign, to tasks that would not have been practical or possible without the technology.

SAMR is best used as a reflective design lens. It helps teachers ask, "What is the technology doing to the learning task?" It should not be used as proof that a lesson is good simply because it uses advanced technology.

## What Problem It Solves

Educational technology is often adopted because it is available, novel, mandated, or engaging. SAMR gives teachers a simple language for distinguishing between different kinds of technology use.

It helps teachers notice whether technology is:

- replacing an existing tool without changing the task;
- adding useful efficiency or feedback;
- enabling a meaningful redesign of the learning process;
- making a new kind of learning activity possible.

The practical value is reflection. SAMR helps teachers avoid using technology only as a digital version of paper, while also avoiding the assumption that every use of technology must be transformative.

## Use When

Use SAMR when:

- reviewing how technology is used in a lesson or task;
- redesigning an existing activity with digital tools;
- discussing whether a tool adds meaningful instructional value;
- helping teachers move beyond tool substitution where appropriate;
- comparing alternative designs for a technology-rich task;
- identifying where technology enables collaboration, feedback, creation, simulation, visualization, data collection, publishing, or access that would otherwise be difficult.

SAMR is especially useful in early conversations about technology integration because the four categories are easy to understand.

## Do Not Use When

Do not use SAMR as:

- a measure of lesson quality by itself;
- evidence that technology improved learning;
- a requirement that every task reach modification or redefinition;
- a hierarchy where substitution is always bad and redefinition is always good;
- a substitute for pedagogy, content knowledge, accessibility, privacy, or assessment design;
- a way to evaluate an entire course without considering context;
- a technology-purchasing justification detached from learning goals.

The major misuse is "climbing the ladder" for its own sake. A substitution-level task may be exactly right when the goal is fluency, access, efficiency, or reduced friction. A redefinition-level task may be poorly designed if it lacks clear learning purpose.

## The Four Levels

Substitution. Technology directly replaces a previous tool with no meaningful functional change. Example: students type an essay instead of handwriting it, with no other change to the writing process.

Augmentation. Technology still replaces a previous tool, but adds functional improvement. Example: students draft in a shared document with comments, spellcheck, revision history, or embedded feedback.

Modification. Technology enables significant redesign of the task. Example: students collaboratively develop a multimedia explanation, receive peer comments from another class, revise from version history, and publish for a specific audience.

Redefinition. Technology enables a new task that would previously have been inconceivable or impractical. Example: students collect live field data with sensors, combine it with public datasets, collaborate with outside experts, and create an interactive model for community use.

The levels are about the task's relationship to technology, not the inherent sophistication of the tool. The same tool can support different levels depending on how it is used.

Same learning goal across levels:

Learning goal: students will use evidence to explain how local temperature patterns have changed over time.

- Substitution: students read a digital article and type answers instead of handwriting them.
- Augmentation: students use a spreadsheet template to calculate averages and create a basic chart from provided temperature data.
- Modification: students gather data from multiple public databases, clean and visualize it collaboratively, annotate patterns, and peer-review explanations in a shared workspace.
- Redefinition: students combine live or historical datasets with an interactive map, compare local patterns with another region through remote collaboration, and publish a public-facing explanation that allows readers to explore the data.

The learning goal stays constant, but the technology changes what students can access, manipulate, collaborate on, and publish. The higher levels are only better if those changes improve evidence use, reasoning, audience, feedback, or transfer.

## Enhancement And Transformation

SAMR is often grouped into two broad zones.

Enhancement includes substitution and augmentation. The basic task remains recognizable, but technology may improve access, speed, feedback, organization, or efficiency.

Transformation includes modification and redefinition. The task changes more substantially because technology enables new forms of collaboration, creation, representation, audience, data use, simulation, or interaction.

This distinction can be helpful, but it should not become a value judgment. Enhancement can be instructionally powerful when the improvement matters.

## How To Apply It

Start with the learning goal. Identify what students should understand, practice, create, or demonstrate. Technology choice comes after the learning purpose.

Describe the original task. What would students do without the technology? What thinking, interaction, product, or evidence would the task require?

Describe the technology-enabled task. What changes? Does technology improve the same task or change the task itself?

Classify tentatively. Ask whether the task is replacement, improved replacement, redesign, or previously impractical/new work. Do not spend too much energy arguing over border cases.

Ask the important question: Does the change improve learning evidence, access, feedback, practice, collaboration, authenticity, creativity, or transfer?

Check tradeoffs. Technology can add cognitive load, privacy risks, access barriers, distraction, inequity, maintenance burden, or shallow production values. A higher SAMR category does not erase those costs.

Revise the task, not just the tool. Moving from augmentation to modification usually requires changes in roles, audience, feedback cycles, representation, collaboration, inquiry, or assessment.

Evaluate learning. Use evidence of student understanding and performance, not the SAMR label, to judge success.

## Examples Across Levels

Writing:

- Substitution: type the final draft.
- Augmentation: use comments and revision history for feedback.
- Modification: co-author, peer review, revise, and publish to an authentic audience.
- Redefinition: create an interactive, multimedia argument that incorporates reader response, data, and revision after public feedback.

Science:

- Substitution: read a digital textbook.
- Augmentation: use embedded simulations to check an idea.
- Modification: collect and analyze real-time data with digital probes.
- Redefinition: collaborate with another location to compare live environmental data and build a shared explanatory model.

History:

- Substitution: view scanned primary sources instead of photocopies.
- Augmentation: annotate sources collaboratively.
- Modification: build a sourced digital exhibit with multiple interpretations.
- Redefinition: create an interactive public archive or oral-history project with geotagged sources and community contribution.

Mathematics:

- Substitution: complete digital worksheets.
- Augmentation: receive immediate feedback on practice.
- Modification: use dynamic graphing to test conjectures and explain parameter changes.
- Redefinition: build and share an interactive model of a local problem using live or user-controlled data.

## Signs Of Strong Implementation

Strong SAMR use is visible when:

- technology choices follow learning goals;
- teachers can explain what functional change the technology provides;
- substitution and augmentation are used intentionally where useful;
- modification and redefinition involve meaningful task redesign, not just fancier products;
- students use technology to think, create, test, collaborate, receive feedback, or reach authentic audiences;
- accessibility, privacy, cost, and equity are considered;
- the SAMR label is treated as a prompt for discussion, not a grade.

## Signs Of Shallow Implementation

Implementation is shallow when:

- teachers are pressured to reach redefinition in every lesson;
- technology is added after the task is designed with no learning purpose;
- digital production value is mistaken for deeper learning;
- SAMR is paired mechanically with Bloom's Taxonomy;
- a task is called redefinition because the tool is new, not because the learning task changed;
- low-tech or no-tech options are ignored even when they would serve the learning goal better;
- evaluation stops at the SAMR category and never asks what students learned.

## Relationship To Nearby Frameworks

TPACK asks whether technology, pedagogy, and content knowledge fit together in a specific teaching context. SAMR asks how technology changes a task. TPACK is broader and more context-sensitive.

The Technology Integration Matrix (TIM) examines characteristics of learning environments such as active, collaborative, constructive, authentic, and goal-directed learning. It is often more pedagogically detailed than SAMR.

TIM and SAMR should not be treated as matching ladders. SAMR focuses on how technology changes a discrete task. TIM examines a richer classroom environment across characteristics such as active, collaborative, constructive, authentic, and goal-directed learning and levels of technology integration. A task can sit high in SAMR without being strong on TIM characteristics, and a lesson can be pedagogically rich while using technology at a modest SAMR level.

Use SAMR when the coaching question is, "How has technology changed this task?" Use TIM when the coaching question is, "What kind of learning environment and student technology use are visible across the lesson?"

UDL asks whether learners have multiple means of engagement, representation, and action/expression. A SAMR redesign can still be inaccessible if it ignores UDL.

Bloom's Taxonomy and DOK address cognitive process and complexity. SAMR does not automatically map to either. A redefinition-level technology use can support memorization, and a high-level creative task can use technology only as substitution.

Puentedura's later writing connects SAMR with broader technology-integration lenses and shared practices. For a teacher-facing handbook, the practical point is simple: SAMR should sit inside a larger design conversation about pedagogy, content, collaboration, assessment, context, and student agency.

Backward Design should come first: desired learning, evidence, then activity and technology choices. SAMR is useful at the activity/tool design stage.

## Design Questions For Teachers

- What is the learning goal?
- What task would students do without technology?
- What does the technology change about the task?
- Is the change mainly replacement, improvement, redesign, or a new possibility?
- What learning benefit justifies the technology?
- What costs or barriers does the technology introduce?
- Does the task require better pedagogy, not more technology?
- What evidence will show that students learned more, learned better, or learned differently?
