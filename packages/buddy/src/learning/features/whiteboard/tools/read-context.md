Read the latest persisted context for the whiteboard identified by `objectID`. Use this immediately before `whiteboard_create_view` with the same `objectID` and `boardAction: "continue_current_board"` when continuing or revising that board so learner edits are preserved. It includes compact rendered bounds when frontend measurements differ from raw geometry; trust those rendered bounds for layout repairs. It is not required only when the user explicitly asks to discard, clear, overwrite, or replace the whole board with `boardAction: "destructively_replace_current_board"`.
