Create or continue the session whiteboard with a compact Excalidraw drawing program. Use this when a visual explanation helps. Load the `whiteboard-authoring` skill before first use. Pass one compact JSON array string in `elements`. It must be valid JSON: no comments, no trailing commas. The argument is already a string field, so write plain JSON inside it, not a second escaped JSON string, and do not wrap it in Markdown fences. Before editing the current board, call `whiteboard_read_context`, then start the array with `{"type":"restoreCheckpoint","id":"<continuation handle>"}`. Omit `restoreCheckpoint` only when intentionally replacing the current board from scratch. Use stable semantic ids. Use `delete` before replacing an existing id, and use `translate` to move related ids together. For local redesigns, delete the old ids and redraw that area with new ids. Do not use this tool for prose-only answers or when a Mermaid diagram is the clearer static representation.
