Present a self-contained local HTML teaching widget to the learner inside Buddy. Use this only after you have created or edited a real `.html` or `.htm` file that should be shown as an interactive lesson widget now, such as a simulation, draggable explanation, one-off quiz, or small visual practice tool. The tool snapshots the existing file into Buddy's widget library and renders that snapshot; it does not edit the file, accept raw HTML source, or create a backend for the widget. Do not use this for normal images, PDFs, videos, documents, or other media files; use `present_media` for those.

Before calling this tool, make the HTML file self-contained with inline CSS and JavaScript. Choose the viewport preset that best matches the layout you authored: `standard_16_10` for most lesson widgets, `wide_16_9` for wide simulations or canvas scenes, `square` for centered manipulatives, `compact_4_3` for small quizzes or controls, and `tall_mobile` only for phone-shaped experiences. The widget runtime blocks network access, remote scripts, remote stylesheets, fetches, forms, popups, and parent Buddy access, so do not rely on CDNs, external assets, or backend calls. If the learner asks for a change later, edit the source file with normal file tools and call this tool again to present a new snapshot.
