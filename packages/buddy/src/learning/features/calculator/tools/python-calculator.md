Evaluate Python code for mathematical calculation, symbolic work, data analysis, and plotting. Use this before making nontrivial mathematical claims, validating worked results, checking algebra, or generating function graphs and data plots. Prefer exact symbolic forms such as fractions, radicals, and symbolic constants before decimal approximations. Import libraries before using them; supported scientific libraries include math, sympy, numpy, pandas, xarray, scipy, matplotlib, and seaborn. Do not use this for explicit geometry diagrams; use render_figure or render_freeform_figure for those.

Plot when the point is a pattern: how a function changes, how two quantities vary together, a distribution, a trend over time, or uncertainty. State a number or two in text, and use a table when the reader needs to look up exact values. Show the finding rather than every data point. Use a line for continuous change or time, bars to compare categories, and a scatter for two quantities together. Make axes, units, scale, series, and uncertainty legible, title the plot with what it shows, and keep the computation or data behind any claim.

For plots, create Matplotlib or Seaborn figures from computed or supplied values. The runtime saves open figures and returns their images inline automatically; do not add `present_media` merely to display the same plots again. Use an HTML widget instead when varying parameters or interacting with the plot is the point.
