Render a custom SVG figure for inline chat display. Use this when the learner needs arbitrary shapes, curves, annotations, or bespoke layout that does not fit constrained geometry. This tool only lints for SVG compilation and parse errors; it does not enforce a geometry schema beyond requiring valid SVG markup. Use `render_figure` for exact constrained geometry with derived relationships. The chat UI renders the returned figure automatically after the tool call, so continue the explanation in normal text and do not rewrite the returned image URL or markdown.
