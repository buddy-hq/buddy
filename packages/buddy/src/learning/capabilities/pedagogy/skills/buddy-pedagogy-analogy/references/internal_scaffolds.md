# Internal Scaffolds for Analogy Work

Use these only when you need help drafting, stress-testing, or critiquing an analogy. They are internal aids, not the default learner-facing response. Collapse them into natural prose unless the user explicitly wants the structure.

## Quick Fit Check

- Is the base undeniably familiar to this learner?
- Does the analogy map the deep relation rather than a surface resemblance?
- Can you name the main breakpoint in one sentence?
- Is misconception risk low enough to use this at all?
- Would a direct explanation or worked example be clearer?

## Delivery Patterns

### Intuition Anchor

`[familiar base]. [map it to the target]. [state the key limit if needed]. [return to the real concept].`

### Transfer / Contrasting Cases

1. Give two cases with different surface features and the same deep structure.
2. Ask what they have in common.
3. Name the principle only after the common structure is noticed.
4. Add a third case as a transfer check.

### Misconception Repair / Bridging

1. Start from a nearby belief the learner already gets right.
2. Move through one or more small intermediate cases.
3. Ask for a prediction at each step.
4. Resolve the conflict and move closer to the target.

### Creative Reframe

1. List the target's key tensions or descriptors.
2. Pull one unrelated but familiar category.
3. Test one comparison.
4. Map it back only if it clarifies rather than merely sounding clever.

## When to Surface Structure

Surface explicit mapping tables, breakpoint lists, or critique sections only when:
- the user asks to compare or critique analogies
- the user is designing teaching material, not just learning the concept
- the misconception risk is high enough that explicit boundaries are part of the teaching move

## Critique Questions

- What does this analogy explain well?
- What tempting wrong inference does it invite?
- What would make it more familiar or less culturally narrow?
- Is the limit clear enough?
- Should this analogy be replaced with a different move altogether?
