Evaluate Python code for mathematical calculation, symbolic work, data analysis, and plotting. Use this before making nontrivial mathematical claims, validating worked results, checking algebra, or generating function graphs and data plots. Prefer exact symbolic forms such as fractions, radicals, and symbolic constants before decimal approximations. Import libraries before using them; supported scientific libraries include math, sympy, numpy, pandas, xarray, scipy, matplotlib, and seaborn. Do not use this for explicit geometry diagrams that should be shown as teaching figures; use render_figure or render_freeform_figure for those.
