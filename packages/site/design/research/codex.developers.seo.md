## Audience-page SEO checklist (what “great” looks like)

1. **Unique title** including Developers + Codex + primary job (“ship code”, “agent”, “PRs”).
2. **Unique H1** — not identical to `/codex` or `/for-work`.
3. **Dev-specific proof:** repo workflows, CI, reviews, CLI, IDE screenshots with alts.
4. **Dev docs links** to API/platform docs (indexed help content).
5. **Pricing path** clarity (Plus/Pro/Business) without keyword spam.
6. **Comparison honesty** section vs generic ChatGPT coding.
7. **Schema:** WebPage + Breadcrumb; SoftwareApplication on parent.

## Risks

- Cannibalization with main `/codex` if copy is too similar.
- Cannibalization with ChatGPT general coding SERPs.
- Empty SSR → social/enterprise security scanners show blank page.

## Recommendations

1. Confirm Google-rendered HTML contains full developer narrative.
2. Differentiate metadata strongly from `/for-work`.
3. Add developer FAQ (models, data retention, repo access, admin controls).
4. Cross-link to changelog / system cards / status only when indexable.
5. Measure GSC queries; if brand-only, expand mid-funnel technical content on help domain.
