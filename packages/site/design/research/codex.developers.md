## Pattern summary

| Aspect | Observation |
|--------|-------------|
| **Narrative** | Positioning headline → trust logos → 5 text-only feature blocks (real work, multi-agent, adapts, background work, quality) → pricing → multi-surface → teams → 6 practitioner testimonials → final CTA |
| **Core pattern** | Text-dense feature blocks (no screenshots in the main feature section). Practitioner testimonials with measurable outcomes. Reuses pricing + multi-surface sections from the main page. |
| **Trust signals** | 4 logos + 6 engineer testimonials with specific results (30-50% faster, "ship in a weekend what took a quarter"). |
| **Distinctive** | No screenshots in the main feature section — text-only. Testimonials are from engineers, not executives (unlike Cursor's CEOs). Reuses sections from the parent page (pricing, multi-surface, teams) — modular page composition. |
