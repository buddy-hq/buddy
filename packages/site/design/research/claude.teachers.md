# Claude for K-12 Teachers — page structure

> Source: https://claude.com/solutions/teachers · Fetched: 2026-07-18
> Referenced by user as the inspiration for Buddy's teacher page. This is a SaaS audience sub-page (not a homepage).

**Product:** Claude for Teachers — free premium Claude access for verified US K-12 educators (teaching skills, Learning Commons curricula connection).
**Page goal:** "Get verified" — sign up educators for the free program. Secondary: Contact sales (districts).
**Tone:** Warm, respectful, teacher-fluent. Speaks in classroom nouns (do-now, exit ticket, formative, IEP, reading levels). Zero tech jargon.
**Visual:** Light, airy. Real output documents (full assessments, misconception analyses) shown at length. Mobile screenshots, teacher photos, partner logos.

### "How educators use Claude" (tabbed use cases — the core section)
- Tabs: **Plan lessons · Differentiate instruction · Assess for understanding · Communicate with families · Anticipate misconceptions**
- Each tab = ONE real prompt + connector logos used + REAL OUTPUT shown at full length:
  - **Plan lessons:** Prompt ("Plan a 45-minute 7th grade math lesson on solving two-step equations. I teach from Illustrative Math and my students have mastered one-step equations. Create student materials that include a do-now, worked example, and exit ticket...") → connectors (Learning Commons, Coteach) → mobile screenshot.
  - **Differentiate:** Prompt ("Make a spreadsheet analysis on how my 4th grade ELA students are performing... put everyone into small groups (reteach, on-level, and extension)...") → attachments shown as files (4th-grade-ELA-lessons PDF, class-reading-levels PDF).
  - **Assess:** Prompt ("Create a 10-question formative assessment for 8th grade science on photosynthesis, aligned to NGSS MS-LS1-6...") → FULL output document: the complete "Photosynthesis Check-In" — parts A/B, 10 questions, answer key with misconception tags, "quick formative read" guidance. Hundreds of words, shown as an artifact.
  - **Communicate:** Prompt ("Every Friday at 3 pm, draft the weekly parent newsletter from this week's lesson plans in my Planning folder...") → scheduled task + Gmail/M365 connectors.
  - **Misconceptions:** Prompt ("What are the most common misconceptions 5th graders have about multiplying fractions?...") → FULL output: 3 misconceptions, each with faulty-mental-model explanation + 3 discussion questions + cross-cutting teaching thread.
- **Note:** This is examples-as-pitch at its most extreme (Codex Work pattern, amplified). The prompts are specific (grade + standard + class context + deliverables). The outputs are REAL, complete teacher artifacts — not UI screenshots, not abstractions. A teacher reads them and recognizes their own work. The copy around them is minimal; the artifacts ARE the pitch.

## Pattern summary

| Aspect | Observation |
|--------|-------------|
| **Narrative** | Emotional hero → trust logos → 3 value blocks (time/rigor/safety) → video → tabbed use cases with REAL artifacts → connector logos → courses → safety section → more tools → examples carousel → testimonials → offer → resources → final CTA. ~15 sections, but each is SHORT copy. |
| **Core pattern** | Artifacts-as-pitch. The use-case tabs show complete, real teacher outputs (full assessments with answer keys, full misconception analyses). Copy stays at 1-2 sentences per block; the artifacts carry hundreds of words without feeling like "text on the page." |
| **Trust signals** | Institutional logos (TFA, AFT, OpenSciEd, Detroit PS), FERPA/AFT Gold Standard, 4 teacher testimonials, named curriculum partners. Maximum social proof — the opposite of Buddy's philosophy-only position. |
| **Conversion** | Single CTA: "Get verified" (repeated hero, mid, final). The free offer is explicit and repeated. |
| **Distinctive** | Teacher-fluent specificity: every prompt names grade + standard + class context + deliverable. Outputs are genuinely usable artifacts. Acronym soup (NGSS MS-LS1-6, IEP, ELA) is used as credibility, not decoration — always attached to a concrete artifact. |
| **vs Buddy's teacher page** | Claude's page is ~15 sections but feels light because copy-per-section is tiny and the weight lives inside artifacts. Buddy's teacher page is 8 sections but feels text-heavy because 4 sections are text-only beats (why, philosophy, ask, agent-beat) and the feature cards carry both description copy AND dense mock microcopy. |

## Relevance to Buddy

### A. Short copy, long artifacts — the density lesson
Claude's page proves a page can be long without feeling text-heavy: copy blocks are 1-2 sentences, and the long text lives inside recognizable artifacts (the check-in, the misconceptions doc). Buddy's feature-card mocks are the equivalent artifact slots — the fix is to keep section copy ruthlessly short and let mocks carry detail.

### B. The tabbed use cases ≈ our 5 feature cards
"How educators use Claude" (plan/differentiate/assess/communicate/misconceptions) maps directly onto Buddy's ALIGN/PLAN/CREATE/RESEARCH/BUILD cards. Same pattern, already implemented. Their tabs show ONE prompt + ONE artifact each — our cards already do this. No new section needed.

### C. The prompt formula: grade + standard + context + deliverable
Every Claude prompt follows: "Plan a [duration] [grade] [subject] lesson on [topic]. [Class context]. Create [deliverables]." Buddy's mock prompts already do this ("Plan tomorrow's lesson on area and perimeter, grade 5. Half my class is still shaky on multiplication."). Validated — keep.

### D. Value blocks: time / rigor / safety
Claude's 3 blocks (more time with students / grounded in standards / safe with student data) are the teacher-page value pillars. Buddy's equivalents: time (Sunday list/ask section), rigor (ALIGN card + teaching skills), safety (philosophy section — Buddy's is stronger: architecture, not policy).

### E. Trust: they spend institutional capital, we spend architecture
Claude burns logos, FERPA, AFT endorsements, and testimonials on trust because they must — data leaves the machine. Buddy's "we can't see anything, by architecture" is a categorically stronger claim and needs no logos. Keep the philosophy section; don't imitate their social-proof stack (we have none).

### F. "Connected to services you trust" ≈ BYO section
Their connector-logo wall maps to Buddy's BYO providers (ChatGPT, API keys, local models). Same job: "works with what you already have."

### G. What NOT to take
- No verification/program offer (Buddy is free for everyone, no gating).
- No testimonials/logos (none exist; philosophy is our trust mechanism — synthesis §6.20).
- No 15-section sprawl. Their page works despite its length because copy is short; Buddy should stay at ~6 sections (Dia's lean end, synthesis §3.7).
- No acronym soup for its own sake — Claude uses standards codes attached to real artifacts; Buddy's earlier draft sprinkled frameworks as decoration and it read as spec-sheet copy.
