## Strategy read

This is **solution/industry SEO** done by a top AI lab:

- Not a homepage — an **ICP landing page** under `/solutions/`.
- Targets education SERPs + branded “Claude for teachers”.
- Copy uses **classroom nouns** (do-now, exit ticket, formative, IEP, reading levels) — lexical alignment with educator search language (matches research intent for Buddy teachers page).
- Conversion: **Get verified** (free Pro for verified US K-12) + Contact sales for districts.
- Trust: student data safety, curricula grounding, educator social proof.

Anthropic’s SEO moat is **domain authority + solution matrix + docs**, not indie hacks.

## Technical SEO

### Strengths
1. Outstanding title + description for audience intent.
2. Canonical correct.
3. High indexable word count with real educational substance.
4. Clear H2 structure (trusted by educators, built for K-12, how educators use Claude, safety, tools, get started…).
5. Sits inside huge claude.com sitemap (discovery OK).
6. Strong OG image specific to teachers.

### Weaknesses
1. **Two H1s** — prefer one primary (`Claude for K-12 teachers`), demote emotional line to H2.
2. **No JSON-LD** — missed `WebPage`, `BreadcrumbList`, maybe `FAQPage` if FAQs visible.
3. Heavy HTML (~1.3MB) — Webflow-ish bulk common on claude.com.
4. `robots` meta not strongly customized (parent may set defaults).
5. Related education page H1 duplication pattern also observed (`higher education` page).

## Architecture context

```
claude.com/solutions/teachers     K-12 educators
claude.com/solutions/education    higher education
claude.com/pricing                plans
claude.com/docs/*                 product education (separate sitemap)
```

Solutions pages are Anthropic’s way to do **segment SEO without separate domains**.

## Recommendations (for Claude page quality; and Buddy lessons)

1. Single H1; keep emotional line as supporting H2.
2. Add BreadcrumbList + WebPage schema; FAQ schema only for visible FAQs.
3. Ensure “Get verified” steps are text-indexable (eligibility, US K-12, privacy).
4. Maintain unique copy vs higher-ed page (already different — keep it that way).
5. Performance budget on Webflow pages.
6. **Buddy takeaway:** educator SEO wins via **domain language + offer clarity + safety**, not via packing 200 generic feature links in a footer.
