# Does the "show ideas" push (N36) apply in the Teach persona too?

**Context**
- Both personas render the same `shared/visual-guidance.p.md` today (`learning-companion.p.md`, `teaching-assistant.p.md`).
- **Learn** (`buddy`): the user is a learner. N36 was decided with them in mind.
- **Teach** (`teaching-buddy`): the user is an educator. They usually ask for materials, plans, and help preparing lessons, not to be taught.

**What differs**
- An educator asking "how do I explain photosynthesis to grade 7?" may want the picture they could use in class, not a lesson for themselves.
- Or they may just want the plan in words, and a push would add visuals they didn't need.

**Options**
- **A. Both personas.** Showing ideas is Buddy's value everywhere.
- **B. Learn only.** Teach gets the room map but no push.
- **C. Both, framed per persona.** Learn: show the learner the idea. Teach: show the educator what they could use with their class.
